**folder**: full path of the Syncthing folder shared with the Kindle (e.g. `C:\Users\you\anki-kindle`).

**days_ahead**: how many days of upcoming reviews (and new cards, at each deck's daily limit) to put on the
Kindle, so you can keep reviewing offline that long.

**enabled**: run automatically (when the profile opens, after each sync, and every `auto_interval_minutes`).
The Tools menu entry always works.

**sync_after_import**: after Kindle reviews are applied, start a normal AnkiWeb sync.

**auto_interval_minutes**: how often to check for new Kindle reviews while Anki is open (0 = only on profile
open and after syncs).
